# Jiji Gomez — AI Engineer Portfolio

A responsive React + Vite portfolio with a dark, elegant black-and-crimson design inspired by the provided reference. It uses plain CSS, Lucide icons, and jQuery for smooth anchor scrolling, header styling, and reveal-on-scroll effects.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL Vite prints (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Customize before publishing
1. Update the email address `your.email@example.com` in `src/App.jsx`.
2. Replace sample GitHub links/descriptions with your exact repository URLs and project details.
3. Add your own portrait and resume PDF if desired. The hero currently uses an abstract CSS neural illustration rather than a placeholder person's photo.
4. Verify the timeline dates and role descriptions before publishing.
5. Remove any skill or project you cannot confidently discuss in an interview.

## Stack
- React + Vite
- Plain CSS
- jQuery (scroll behavior and reveal effects)
- Lucide React icons

The site is frontend-only; no API keys or backend are required.
